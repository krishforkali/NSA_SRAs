# Logo slots

The globe page shows text marks for NASA, ISRO and NISAR. If you have permission to use the
official logos, put them here and they replace the text marks automatically:

- `nasa.png`, `isro.png`, `nisar.png` (transparent PNG, about 64 px tall)

The NASA insignia and the ISRO logo are protected marks: their use needs the agency's approval and
must not suggest endorsement. Many challenge rules (for example NASA Space Apps) do not allow the
NASA logo on entries, so check your challenge's rules first.
